# עכבר ההר 🐭🏔️

מדריך קהילתי **חי, ויזואלי ונגיש** לאזור מרום גולן ורמת הגולן — אוכל, טיולים,
בריאות, עסקים ואנשי קשר. דף HTML יחיד שמתעדכן **ישירות מגיליון Google Sheets**
שיתופי שכל תושב מוסיף אליו.

➡️ הקובץ היחיד שצריך כדי להריץ: **[`index.html`](./index.html)**

## איך זה עובד

```
תושב מוסיף שורה בגיליון  ─►  index.html קורא את הטאבים (gviz CSV)  ─►  כרטיסים + מפה
```

- בטעינה הדף מושך כל טאב מהגיליון דרך `…/gviz/tq?tqx=out:csv&gid=<gid>` ומפענח
  עם PapaParse. כל טאב = קטגוריה.
- אם הרשת/גוגל לא זמינים, הדף מציג מיד **תמונת-מצב מובנית (SEED)** ואת ה-cache
  האחרון מ-`localStorage` — אז הוא אף פעם לא "נשבר" ולא נשאר ריק.
- לכל מקום: שם, תת-כותרת + יישוב, **כפתור התקשרות** (אם יש טלפון) ו**"במפות גוגל"**
  שמבצע חיפוש אמיתי של המקום. אין מעבר לעמוד נפרד — הכול בכרטיס.

## הרצה מקומית

זה קובץ סטטי. אפשר פשוט לפתוח אותו בדפדפן, או:

```bash
cd achbar-hahar
python3 -m http.server 8080
# פתחו http://localhost:8080
```
> בפתיחה ישירה כ-`file://` חלק מהדפדפנים חוסמים את הקריאה מהגיליון (CORS),
> אז הדף יציג את ה-SEED. בהרצה דרך שרת/אירוח אמיתי הקריאה החיה עובדת.

## אירוח (מומלץ — חינמי)

## תחזוקה

### הוספת/עריכת מקומות
לא נוגעים בקוד — עורכים את [הגיליון](https://docs.google.com/spreadsheets/d/1FvKhqpVX_nmi6LshkqSVU2f4XmdAD6DFEE9Ra1GCzRE/edit).
כפתורי "הוספת מקום" בדף פותחים אותו.

### שינוי מבנה גיליון / טאב חדש
עורכים את מערך `TABS` בראש ה-`<script>` ב-`index.html`:
```js
{gid:"<מזהה הטאב>", cat:"<קטגוריה>", start:<שורת ההתחלה>, cols:{name:0, sub:1, settlement:2, phone:3, notes:4}}
```
`start` = האינדקס של שורת הנתונים הראשונה (מדלגים על כותרות/שורות הסבר).
`cols` ממפה תפקיד → אינדקס עמודה. כל תפקיד אופציונלי.

### מיקומים על המפה
המפה משתמשת בקואורדינטות **משוערות ברמת היישוב** (טבלת `GEO` ב-`index.html`,
התאמה לפי תת-מחרוזת). להוספת יישוב חדש — מוסיפים שורה ל-`GEO`. לדיוק מלא אפשר
בעתיד להוסיף עמודות `lat`/`lng` בגיליון ולקרוא אותן ב-`TABS`.
